# Known Limitations

- Runme currently only has rudimentary support for PowerShell. While PowerShell is not limited to Windows, it is its primary platform. We recommend using [WSL](../installation/windows).
- When the Runme VS Code extension’s shell warning is enabled, it can warn if you use a default shell such as Fish. If you see this warning, try Bash or Zsh as your default shell. With Fish installed, you can still run cells explicitly labeled `fish`. See the [list of auto-detected language runtimes](../usage/shebang.md#list-of-auto-detected-language-runtimes).
- Please [report any issues](https://github.com/runmedev/runme/issues/new) you encounter, big or small, to help us make Runme better.
